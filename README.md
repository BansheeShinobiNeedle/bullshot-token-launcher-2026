## 🔥 Why This Exists

Bullshot is one of the fastest-growing meme token platforms on BNB Chain. It raised $7.7 million in October, led by P2 Ventures and Animoca Brands, with AWS participating. The platform has processed over $85 million in trading volume and launched 210,000+ tokens.

But the interface is built for speed, not analysis. If you're launching a token, you want to know: how close is the Bonding Curve to PancakeSwap migration? How much will you earn? Did you miss a quest?

This companion answers those questions. It's read-only. No wallet connection. No transactions. Just data and calculators.

## 🧩 What It Does

### Bonding Curve Tracker
- Monitor any Bullshot token's progress toward migration

- Liquidity lock status

### Creator Fee Calculator
- Input token supply, initial price, and expected volume
- Estimates creator revenue share based on Bullshot's fee structure
- Compares scenarios (low volume vs. high volume)

### Quest Manager
- Track daily check-in, social tasks, and weekly quests
- Checklist view with completion status
- Reminder for unclaimed points

### Multi-Chain View

- Track tokens across all networks in one list
- Filter by chain

## ❓ FAQ

**Does this create or trade tokens for me?**
No — it's a read-only tracker and calculator. No wallet connection, no transactions, no key access.

**Do I need a Bullshot account?**
No — the tracker uses public data. For quest tracking, you manually check off tasks you've completed.

**How accurate is the Bonding Curve tracker?**
It pulls public on-chain data. Migration timing is estimated based on recent velocity, not guaranteed.

**Does it work with all Bullshot chains?**
Yes — BNB Chain, Robinhood Chain, Base, and ARC Chain are supported.

**Will I get banned?**
This is a read-only data viewer. It does not interact with the Bullshot platform or execute transactions.

**How do I uninstall?**
Delete the tracker folder. No registry entries or system changes are made.
